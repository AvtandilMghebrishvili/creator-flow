# Contributing

Use a virtual environment and install `python -m pip install -e '.[dev]'`. Install FFmpeg/ffprobe, then run `python -m pytest -q`. Tests use generated media; they must never require private footage or download a speech model during CI. `python -m build` verifies packaging.

Keep source paths and timebases explicit. Tests should catch timing, stale-state, speaker-track or delivery regressions, not simply repeat implementation details. Code under `src/podcut/` separates inventory, sync, color, planning, audio, transcripts, exports and the optional native Premiere adapter. Update the matching guide when behavior changes.

Do not commit real episode footage/audio, transcripts, native projects, copied commercial presets, local credentials, bridge configuration or machine-specific paths. Run `python scripts/check_release.py` after staging files to check the public file list. Synthetic assets should be generated by tests, not checked in as large binaries.

The canonical agent instructions are START_HERE.md. Keep Codex and Claude skill entrypoints short and consistent with it. New adapters must label unverified behavior honestly and preserve the simpler exchange-package fallback. Report test evidence and any remaining native-app validation in change descriptions.
