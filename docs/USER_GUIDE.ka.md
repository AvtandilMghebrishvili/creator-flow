**Creator Flow** არის ერთი სამუშაო ფლოუ პოდკასტის, YouTube Shorts-ისა და Instagram Reels-ისთვის. აგენტი მართავს ადგილობრივ ინსტრუმენტებს, შენ კი ირჩევ შედეგს, ამოწმებ ტექსტს და ადასტურებ მონტაჟის მნიშვნელოვან გადაწყვეტილებებს.

## 1. პირველად — დააყენე პირდაპირ ჩათიდან

გამოიყენე **ადგილობრივი Codex ან Claude Code**, რომელსაც კომპიუტერზე ფაილების წაკითხვა და ბრძანებების გაშვება შეუძლია. ჩვეულებრივ ვებჩატში მარტო GitHub ბმულის ჩაგდება დისკზე წვდომას არ აძლევს. უკვე დაყენებული აგენტი გამოიყენე; Creator Flow თავად Codex-ს, Claude-ს ან Adobe-ს არ აყენებს.

ჩათში ჩასასმელი ტექსტი:

```text
დააყენე Creator Flow ამ კომპიუტერზე:
https://github.com/AvtandilMghebrishvili/creator-flow

წაიკითხე START_HERE.md და docs/SETUP.md.
თუ checkout უკვე არსებობს, გამოიყენე ის; არ შექმნა დუბლიკატი.
შეამოწმე და დააყენე საჭირო პროგრამები. Meta Omnilingual ASR იყოს ნაგულისხმევი.
მინდა პოდკასტებზე, Shorts/Reels-ზე და YouTube არქივზეც მუშაობა.
გაუშვი ერთიანი ინსტალატორი არქივის კომპონენტებით და შეამოწმე ორივე doctor.
scripts/register_skill.py-ით creator-flow ამ კლიენტისთვის პირად skill-ად დაარეგისტრირე.
არსებული ჩემი ინსტრუქციები შეინახე; შეცვლის საჭიროებისას გააკეთე backup.
ბოლოს მითხარი სად დაინსტალირდა და როგორ გამოვიძახო. ეპიზოდი ჯერ არ დაამუშაო.
```

აგენტი ამოწმებს Python-სა და FFmpeg/ffprobe-ს, ქმნის ან იყენებს პროექტის `.venv`-ს, ამატებს Meta-ს ბიბლიოთეკებს და არქივისთვის Node/yt-dlp-ს. უკვე გამართულ პროგრამებს ხელახლა არ აყენებს. **მოდელის წონები** პირველ მოკლე ASR ტესტზე იტვირთება; დაყენებული ბიბლიოთეკა ჯერ არ ნიშნავს, რომ მოდელი მოსმენით შემოწმებულია. Premiere-ის MCP/პლაგინი საჭიროა მაშინ, როცა აპში ავტომატური აწყობა გინდა; Adobe-ში შესვლა და სავალდებულო ინტერაქტიული ნაბიჯები შესაძლოა შენ გააკეთო.

მხოლოდ ინსტალაციისთვის ეპიზოდის ფოლდერი საჭირო არ არის. თუ YouTube არქივი არ გჭირდება, უთხარი აგენტს და `-WithArchive` გამოტოვდება.

## 2. როგორ გამოიძახო skill

| სად წერ | ჩათში შესაყვანი ფორმა |
| --- | --- |
| Codex | `$creator-flow` და შემდეგ შენი დავალება |
| Claude Code | `/creator-flow` და შემდეგ შენი დავალება |
| ჩვეულებრივი ტექსტით, ორივეგან | `გამოიყენე creator-flow skill. ...` |

Codex-ში skill-ის ასარჩევად გამოიყენე `$`; CLI/IDE-ში ხელმისაწვდომია `/skills`-იც. Claude Code-ში გამოიყენე `/creator-flow`. ეს ფორმები **ჩათისთვისაა**, ტერმინალში სამუშაო ბრძანება კი `creator-flow`-ია. [Codex-ის ოფიციალური ინსტრუქცია](https://learn.chatgpt.com/docs/build-skills), [Claude Code-ის ოფიციალური ინსტრუქცია](https://code.claude.com/docs/en/skills).

სახელის შემდეგ დაწერილი „პოდკასტი“, „Shorts“ ან „Reels“ შენი მოთხოვნაა; ეს სიტყვები ცალკე პროგრამული ქვებრძანებები არ არის. მაგალითად, `creator-flow reels` ტერმინალის მხარდაჭერილი ბრძანება არ არის.

**ახალ ჩათში:** გახსენი ეპიზოდის პროექტი და მიუთითე ზუსტი ფოლდერი. პირადი skill-ის რეგისტრაციის შემდეგ workflow-ს repo-ს გარეთაც გამოიძახებ. რეგისტრაციის გარეშე შეგიძლია იმუშაო Creator Flow-ის checkout-ში, სადაც repo-ს skill უკვე დევს, ან აგენტს პირდაპირ წააკითხო checkout-ის `START_HERE.md`. ფაილებზე წვდომა მაინც საჭირო იქნება.

## 3. ფაილები როგორ მოამზადო

შეინახე ორიგინალები ერთ ეპიზოდის ფოლდერში; სახელები თავისუფალია:

```text
Episode-01/
  cameras/
    guest-001.mov
    host-001.mp4
    wide-001.mp4
  audio/
    guest.wav
    host.wav
```

ყველა ფაილი სავალდებულო არ არის. აგენტს უთხარი, რომელი ვის ეკუთვნის. კამერის რამდენიმე ნაწილის შემთხვევაში მიაწოდე ყველა ნაწილი. ერთ აუდიოფაილში მარცხენა/მარჯვენა არხზე სხვადასხვა მიკროფონი თუა, ესეც მიუთითე. ერთი საერთო კადრისა და საერთო ხმის შემთხვევაში აგენტი გკითხავს ვინ სად ზის და ვინ საუბრობს კონკრეტულ მონაკვეთებში; დამოუკიდებელი სუფთა ხმების აღდგენა გარანტირებული არ არის.

**Checkout და ჩანაწერები ცალკე შეინახე.** პირადი ვიდეოები, ტრანსკრიპტები და ფონტები საჯარო GitHub-ზე არ უნდა მოხვდეს. სამუშაო მდგომარეობა ეპიზოდის `.podcut/`-ში ინახება.

## 4. სრული პოდკასტი — თავიდან Premiere-მდე

Codex-ში ჩასასმელი მაგალითი; Claude Code-ში პირველი სიტყვა შეცვალე `/creator-flow`-ით:

```text
$creator-flow ახალი პოდკასტი დავამუშაოთ.
ფოლდერი: D:\Podcasts\Episode-01
guest-001.mov სტუმარია; host-001.mp4 წამყვანია; wide-001.mp4 საერთო კადრია.
ცალკე ხმებია audio/guest.wav და audio/host.wav.
დაიწყოს მისალმებითა და სტუმრის წარდგენით, დასრულდეს დამშვიდობებით.
ფერები დამუშავებული არ არის — ჯერ მაჩვენე ვარიანტები.
Meta-ს სრული ტრანსკრიპტი ტაიმკოდებით მაჩვენე ჩასწორებისა და დასტურისთვის.
ჰუკი იყოს დასაწყისში ტიზერად და მოგვიანებით სრულ საუბარშიც დარჩეს.
სუბტიტრების არჩევანი მკითხე. ხმა და კამერები ცალკე ტრეკებზე შეინარჩუნე.
Premiere-ში ამიწყვე; სრულ ვიდეოს მე დავარენდერებ.
```

აგენტი შეადგენს ფაილების რუკას, ამოწმებს სინქრონს დასაწყისში/შუაში/ბოლოში და საჭიროებისას საათების აცდენასაც ასწორებს. ფერისთვის გაჩვენებს **შენი კამერების რეალურ კადრებს** რამდენიმე ვარიანტით. კამერის საცნობარო ხმა ანალიზს ემსახურება; ცალკე მიკროფონების არსებობისას საბოლოო მონტაჟში ისინი გამოიყენება.

Meta ქმნის ტექსტის მონახაზს. შენ ამოწმებ სრულ ტექსტსა და დროებს, შემდეგ ჰუკს/მონტაჟს/სუბტიტრებს. დასტურის შემდეგ აგენტი აწყობს პროექტს. Premiere-ის შემთხვევაში უნდა შეინახოს `.prproj`, ხელახლა გახსნას და შეამოწმოს ბმულები, ტრეკები და დაკვრა. XML ჯერ მხოლოდ გაცვლის ფაილია. [Premiere-ის დეტალები](PREMIERE.md).

## 5. YouTube Shorts — გრძელი ვიდეოდან მოკლე ამბები

```text
$creator-flow ამ ეპიზოდიდან YouTube Shorts მინდა.
ფოლდერი: D:\Podcasts\Episode-01
ექსპორტირებული სუფთა ვიდეო: exports/episode-clean.mp4
თუ matching ტრანსკრიპტი არ გვაქვს, გამოიყენე Meta.
შემომთავაზე რაოდენობა და ხანგრძლივობა შეკითხვის ფორმით და დაელოდე ჩემს არჩევანს.
შემდეგ მაჩვენე სრული ტრანსკრიპტი და შემომთავაზე დამოუკიდებლად გასაგები მონაკვეთები.
თითოეულს ჰქონდეს რეალური ჰუკი დასაწყისში; ჰუკი სრულ მონაკვეთშიც დარჩეს.
მკითხე სუბტიტრები მინდა თუ არა და მაჩვენე რეალური ფონტის/ფერის ვარიანტები.
ფორმატი იყოს ვერტიკალური 9:16. დამზადებამდე დავადასტურებ არჩევანს.
```

აგენტის შეკითხვა შეიძლება იყოს: **„სამი 45–60-წამიანი Shorts მოვამზადოთ, თუ სხვა რაოდენობა/დრო გირჩევნია?“** ეს მაგალითია, არა ავტომატური არჩევანი ან პლატფორმის ლიმიტი. თუ რაოდენობა/დრო უკვე მიუთითე, ხელახლა არ გკითხავს.

ვარჩევთ დასრულებულ აზრს: საინტერესო დასაწყისი, გასაგები კონტექსტი და დასასრული. ავტომატური ქულა მხოლოდ კანდიდატების მოძებნაში გვეხმარება; ნახვებს არ პროგნოზირებს. საერთო კადრისთვის შეიძლება სრული სურათის ჩასმა დაბლარულ ფონზე; ცენტრალური crop მხოლოდ შემოწმებული კადრისთვის. რენდერი ამოწმებს ტექნიკურ შედეგს, აგენტი კი რეალურ კადრებსა და ხმას.

## 6. Instagram Reels — იგივე მასალა, ცალკე არჩევანი

```text
/creator-flow ამ ეპიზოდიდან Instagram Reels მოვამზადოთ.
ფოლდერი: D:\Podcasts\Episode-01
სუფთა ვიდეო: exports/episode-clean.mp4
ენა: ქართული. ფორმატი: 9:16.
შემომთავაზე რაოდენობა და ხანგრძლივობა, ჯერ ჩემი პასუხი მიიღე.
შემდეგ სრული ტექსტი ტაიმკოდებით მაჩვენე; მომეცი მონაკვეთებისა და ჰუკების არჩევანი.
რეალური ჰუკი დასაწყისშიც იყოს და საუბარშიც დარჩეს.
სუბტიტრების ჩართვა, ნამდვილი ფონტი, ზომა და ფერი შემათანხმე.
ინტერფეისის ღილაკებისთვის სივრცე დატოვე და crop-ში სახეები არ მოიჭრას.
ვიდეოები ჯერ გადამამოწმებინე; Instagram-ზე ავტომატურად არ ატვირთო.
```

აქ მაგალითი Claude Code-ისთვისაა; Codex-ში გამოიყენე `$creator-flow`. Shorts და Reels იყენებს ერთსა და იმავე შემოწმებულ კლიპების მოდულს. **ცალკე „Reels AI“ არ მუშაობს**: იცვლება შენი brief, მონაკვეთის არჩევანი, ტემპი, კადრის განლაგება და ტექსტის მდებარეობა. პლატფორმის საბოლოო ნახვაში შეამოწმე, რომ ღილაკები ტექსტს არ ფარავს. დროის მაგალითი შეიძლება იყოს 15–45 წამი, მაგრამ საბოლოოს შენ ირჩევ.

ერთი მოწონებული კლიპი შეიძლება ორივეგან გამოიყენო. თუ განსხვავებული ტექსტი/crop/ხანგრძლივობა გინდა, ვამზადებთ ცალკე დადასტურებულ ვერსიებს. სამი კლიპის სუფთა და ტექსტიანი ასლები სამი შინაარსია, ექვსი ფაილი.

## 7. ტექსტი, ჰუკი და სუბტიტრები როგორ მოწმდება

ჯერ ნახავ **მთელ ტრანსკრიპტს**, არა მხოლოდ საინტერესო ფრაზებს. შეგიძლია ჩათში დაწერო: `00:12:34-ზე „X“ შეცვალე „Y“-ით`. სურვილისამებრ გახსნი ადგილობრივ `review.html`-ს: მიუთითებ ვიდეოს მოსასმენად, შეასწორებ არსებულ ტექსტს/დროებს და გადმოწერ ცვლილებების JSON-ს. JSON დაუბრუნე აგენტს ან მიუთითე შენახული ფაილი. გვერდის გახსნა ან ჩასწორება ავტომატური დასტური არ არის.

ჰუკის მაგალითი: წყაროს `00:12:10–00:12:15` მონაკვეთი ვიდეოს პირველ 5 წამში მოთავსდება; შემდეგ ძირითადი საუბარი გაგრძელდება და იგივე მონაკვეთი თავის ადგილასაც დარჩება. ვიდეოსთან ერთად აუდიო და სუბტიტრების დროებიც იცვლება. 50-წამიანი ძირითადი მონაკვეთი + 5-წამიანი ტიზერი = 55 წამი.

მაჩვენე ტიტრების White, Yellow და Mint ვარიანტები რეალური ქართული ფონტით.

## 10. ტერმინალიდან დაყენება და skill-ის რეგისტრაცია
