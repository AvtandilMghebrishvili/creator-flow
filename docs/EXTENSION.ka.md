# Creator Flow პირდაპირ YouTube-ში

[ტექნიკური ინსტრუქცია / English](EXTENSION.md)

Chrome/Edge გაფართოება YouTube-ის ვიდეოსა და არხის გვერდზე გაჩვენებს შეფასებას, ტექსტების ვარიანტებს, თაბნეილის პრევიუს, ანალიტიკასა და ახალ იდეებს. პირველი ვერსია ადგილობრივად იტვირთება; ბრაუზერების მაღაზიებში ჯერ გამოქვეყნებული არ არის.

## დაყენება

1. ჩამოტვირთე Creator Flow, ან გაშალე გაფართოების ZIP.
2. Chrome-ში გახსენი `chrome://extensions`, Edge-ში `edge://extensions`.
3. ჩართე **Developer mode**, დააჭირე **Load unpacked** და აირჩიე ფოლდერი, სადაც `manifest.json` დევს. რეპოზიტორიაში ესაა `extensions/creator-flow`.
4. განაახლე YouTube-ის გვერდი. ქვედა მარჯვენა კუთხეში დააჭირე **Creator Flow**.

ეს ნაბიჯი Chrome/Edge-ში კეთდება. Codex-ის ჩაშენებულ ბრაუზერს გაფართოების ინსტალაცია არ ევალება. ბრაუზერის უსაფრთხოების პარამეტრების იძულებითი შეცვლა არ ხდება.

## რა არის თითოეულ ჩანართში

| ჩანართი | რისთვის გამოიყენება |
| --- | --- |
| შეფასება | მიმდინარე გვერდის მონაცემები და სათაურის/აღწერის გამჭვირვალე შემოწმება |
| შეფუთვა | თაბნეილი დიდ და მცირე ზომაში; სათაურის, აღწერის და თეგების სამუშაო ვერსიები |
| ანალიტიკა | არხზე ჩატვირთული ვიდეოების ნიმუში, ან შენ მიერ შემოტანილი Studio ანგარიშის რეალური მეტრიკები |
| იდეები | თემაზე მორგებული ადგილობრივი შაბლონები, ან AI-ის ახალი იდეები ჰუკითა და დასაბუთებით |
| AI კავშირი | მოდელთან დაკავშირება ან კონტექსტისა და ანგარიშის გაცვლა Codex/Claude-თან |

პირველივე გაშვებაზე მუშაობს საჯარო გვერდის შემოწმება, პრევიუები და ტექსტების შაბლონები. ეს არ არის ნახვების ან CTR-ის პროგნოზი. YouTube-ზე არაფერი ქვეყნდება ან იცვლება. სრული აღწერისთვის თავად გახსენი აღწერა და პანელში დააჭირე განახლებას.

## რეალური ანალიტიკის შემოტანა

YouTube Studio → Analytics → Advanced mode → ვიდეოების ანგარიში → CSV export.

გაფართოების პარამეტრებში მიუთითე არხის ზუსტი URL, ანგარიშის საწყისი/საბოლოო თარიღი და CSV. გამოიყენე ინგლისური სვეტების სახელები და ათწილადის წერტილი. შემოტანა ადგილობრივია.

ნახვები, ყურების საათები, CTR და გამომწერები გამოჩნდება მხოლოდ თუ ფაილშია. CTR იმპრესიებით იწონება. გამოტოვებული მნიშვნელობა ნულად არ ჩაითვლება. ანგარიშის პერიოდი ყოველთვის ჩანს. ეს CSV-ზე დაფუძნებული ანგარიშია; Google ანგარიშის ცოცხალი OAuth კავშირი ამ ვერსიაში არ არის.

საჯარო არხზე იკითხება მაქსიმუმ 200 უკვე ჩატვირთული ბარათი. Shorts და გრძელი ვიდეოები ცალკე ჩანს. ეს სრული არხის აუდიტს თავისით არ უდრის და დაბალი ნახვები კონკრეტულ მიზეზს ვერ ამტკიცებს.

## AI-ის დაკავშირება

პარამეტრებში ნახავ **Extension ID**-ს და მზა ბრძანებას. ტერმინალში გაუშვი:

```sh
creator-flow extension-serve --workspace "PRIVATE_WORKSPACE" --extension-id YOUR_EXTENSION_ID
```

`PRIVATE_WORKSPACE` შეცვალე პირადი ფოლდერით, საჯარო რეპოზიტორიის გარეთ. ტერმინალი გაჩვენებს `connection.json`-ის ადგილს. მისი URL და pairing token ჩაწერე გაფართოების პარამეტრებში და დააკავშირე. ტერმინალი ღია უნდა დარჩეს. ხელახლა გაშვებისას ახალი token გამოიყენე.

AI მოდელისთვის ბრძანებას დაამატე ერთ-ერთი:

```sh
--provider ollama --model YOUR_INSTALLED_MODEL
--provider openai --model YOUR_API_MODEL
```

Ollama იყენებს უკვე დაყენებულ ადგილობრივ მოდელს. OpenAI-სთვის ტერმინალის გარემოში უნდა იყოს `CREATOR_FLOW_OPENAI_API_KEY`. API-ის საფასური ChatGPT-ის გამოწერისგან ცალკეა. გასაღები გაფართოებაში არ ინახება; მოდელის ჩამოტვირთვა ან ფასიანი მოთხოვნა ავტომატურად არ იწყება.

**AI კონტექსტის გაგზავნას შენ წყვეტ.** ღილაკი გაჩვენებს არჩეულ სერვისსა და მოდელს. იგზავნება გვერდის ტექსტი, იმპორტის ჯამები და მაქსიმუმ 100 ვიდეოს რიგი. თაბნეილის რეალური შეფასებისთვის ცალკე მონიშნე სურათის გაგზავნა და გამოიყენე გამოსახულების მხარდამჭერი მოდელი. მონიშვნის გარეშე სურათი AI-ს არ გადაეცემა.

ანგარიში YouTube-ის პანელშივე გამოჩნდება: აღმოჩენები, გასაუმჯობესებელი ნაბიჯები, სათაურები, აღწერა, თეგები და იდეები. მოდელს ფაქტების, ტრენდების ან არხის შედეგების გამოგონების უფლება არ ეძლევა, თუმცა პასუხი მაინც გადასამოწმებელია.

## არსებული Codex / Claude ჩათით გამოყენება

AI ჩანართში გაიტანე კონტექსტის JSON და დააკოპირე დავალება. მიეცი ჩათს ორივე, შემდეგ მიღებული ანგარიშის JSON შემოიტანე გაფართოებაში. ფორმატი აღწერილია [ტექნიკურ გზამკვლევში](EXTENSION.md#use-your-existing-codexclaude-chat-instead).

ჩათში დაკავშირებული vidIQ გაფართოებას ავტომატურად არ გადაეცემა. შენს აგენტს შეუძლია მისი გამოყენება შესაბამისი ავტორიზაციით; ანგარიში შემდეგ JSON-ით ბრუნდება. შეცვლილ გვერდზე ძველი ანგარიში არ გამოიყენება.

## რა არ არის ჯერ დამატებული

- Google OAuth-ით მუდმივი პირდაპირი კავშირი და ცოცხალი არხის სრული ანალიტიკა.
- ჩაშენებული vidIQ ავტორიზაცია, keyword-volume ბაზა და ავტომატური ტრენდების კვლევა.
- YouTube-ზე სათაურის/თაბნეილის შეცვლა, ატვირთვა ან A/B ტესტის გაშვება.
- Chrome Web Store/Edge Add-ons-ში გამოქვეყნება.

ეს ფუნქციები არ არის წარმოდგენილი თითქოს მუშაობდეს. მოქმედი პირველი ვერსია გაძლევს გვერდზე სამუშაო პანელს, ნამდვილ CSV მეტრიკებს და არჩევით AI/აგენტის კავშირს.
