# Creator Flow Studio

[English / ტექნიკური ინსტრუქცია](STUDIO.md)

Studio აერთიანებს შენს კონექტორებს, პროექტის საერთო მეხსიერებას და ადგილობრივ ვიდეოსამუშაოებს. გაფართოების **CF** ღილაკი ხსნის ამ მართვის პანელს.

## დაყენება

Creator Flow-ის ძირითადი ინსტალაციის შემდეგ, პროექტის ფოლდერში გაუშვი:

```powershell
.\Install-Studio.ps1
.\Start-Studio.ps1
```

ინსტალატორი ამატებს საჭირო Python ბიბლიოთეკას, ოფიციალურ Gemini CLI-ს და უცვლელ Claude Code-ს. CLI-ებისთვის საჭიროა Node.js 22+. მხოლოდ ChatGPT-ისთვის შეგიძლია გაუშვა `Install-Studio.ps1 -WithoutVendorClis`.

გახსენი `http://127.0.0.1:8772/studio/`. ტერმინალი დატოვე გაშვებული. შემდეგ ჩართვაზეც გამოიყენე `Start-Studio.ps1`. პარამეტრით `-Workspace "PRIVATE_FOLDER"` შეგიძლია პირადი მონაცემების ფოლდერი აირჩიო. ის Git რეპოზიტორიის გარეთ უნდა იყოს.

გაფართოების ძველი ვერსია თუ გიყენია, Chrome/Edge-ის გაფართოებების გვერდზე დააჭირე Reload-ს და განაახლე YouTube. ეს ვერსიაა 0.2.0. გაფართოება და ადგილობრივი სერვისი ერთ კომპიუტერზე უნდა მუშაობდეს.

## კონექტორების მიერთება

**ChatGPT:** დააჭირე **Continue with ChatGPT**, შედი ოფიციალურ გვერდზე და მიეცი გამოწერის გამოყენების უფლება. დაბრუნდი Studio-ში, განაახლე გვერდი, აირჩიე ანგარიში და მისი მოდელების სიიდან მოდელი. ჩართე კონექტორი და შეინახე.

ეს ოფიციალური კავშირი შენი ChatGPT გეგმის დაშვებულ ლიმიტს იყენებს. ცალკე დეველოპერის API გასაღები საჭირო არ არის. ტექნიკურად მოთხოვნა ოფიციალურ Responses მისამართზე მიდის; ბილინგის წყარო შენ მიერ ავტორიზებული გამოწერაა. ლიმიტები და კრედიტები ნახე **Manage usage**-ში. [ოფიციალური აღწერა](https://developers.openai.com/siwc/token-sharing-open-source).

**Gemini:** აირჩიე ოფიციალური CLI და გახსენი შესვლის ტერმინალი. Gemini-ში მონიშნე **Sign in with Google** და გამოიყენე შენი Google ანგარიში. CLI-ის დაშვებები და ლიმიტები ამ ანგარიშზეა დამოკიდებული. [შესვლა](https://geminicli.com/docs/get-started/authentication/).

**Claude:** შესვლა სრულდება უცვლელ ოფიციალურ Claude Code-ში, შენი ანგარიშით. პანელის ღილაკი ხსნის მის შესვლის ტერმინალს. Creator Flow არ აკოპირებს Claude-ის ტოკენებს და არ ქმნის საკუთარ Claude.ai ავტორიზაციის სისტემას. [ოფიციალური პირობები](https://code.claude.com/docs/en/legal-and-compliance).

თითოეულისთვის შეგიძლია აირჩიო **ჩათში გადატანა**: დააკოპირებ მომზადებულ დავალებას, შეასრულებ პროვაიდერის ოფიციალურ ჩათში და პასუხს აქ დააბრუნებ. ჩართვის ღილაკი თავისით არც შესვლას ამოწმებს და არც გენერაციას იწყებს.

## როლები

ერთი ჩართული კონექტორი იღებს ყველა იმ როლს, რომლის შესრულებაც შეუძლია. რამდენიმე კონექტორისას თავად ანაწილებ:

| როლი | მაგალითად |
| --- | --- |
| იდეები | Gemini |
| ტექსტები | Claude |
| შეფასება | ChatGPT |
| სურათები | ChatGPT ან Gemini |

ეს მხოლოდ განაწილების მაგალითია. ხარვეზისას სხვა კონექტორზე ან ცალკე ფასიან API-ზე ავტომატური გადართვა არ ხდება.

**სურათებს ამ ვერსიაში ჩათში გადატანა სჭირდება.** ChatGPT-ის გამოწერის პირდაპირი კავშირი image generation-ს ჯერ არ უჭერს მხარს. პანელი ამზადებს დავალებას საერთო კონტექსტით, შენ ხსნი ოფიციალურ ChatGPT/Gemini-ს, იქ ქმნი სურათს და მიღებულ PNG/JPEG/WebP-ს პროექტში აბრუნებ. Claude აქ გამოსახულების შემქმნელად არ ინიშნება. [შესაძლებლობების ზღვარი](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations).

## საერთო მეხსიერება

შექმენი პროექტი და შეავსე ბრიფი, აუდიტორია, სტილი, სწორი სახელები და გადაწყვეტილებები. არჩეული კონექტორი მიიღებს ამავე პროექტის მიმდინარე ვერსიას. დავალების დაწყებამდე ჩანს, რომელი კონტექსტი იგზავნება.

AI-ის პასუხი ავტომატურად დამტკიცებულ ფაქტად არ იქცევა. მიღების ღილაკით შეგიძლია დაამატო საერთო მეხსიერებას. ძველი ვერსიის პასუხს ახალი მეხსიერების გადაწერა არ შეუძლია. თითოეულ პროექტს თავისი ჩანაწერები აქვს.

YouTube-ის გაფართოებიდან შეგიძლია კონტექსტის JSON გამოიტანო და პროექტს მიაბა. მეხსიერებაც JSON-ით გადის. ეს არ ნიშნავს შენი პირადი ჩათების მთელი ისტორიის სინქრონიზაციას სამ პროვაიდერს შორის.

## ვიდეო და რილსები

პროექტის შექმნისას მიუთითე ეპიზოდის არსებული პირადი ფოლდერი. ფაილები კომპიუტერზე მუშავდება.

1. არსებული Creator Flow ეპიზოდისთვის პანელიდან გაუშვი ინვენტარიზაცია, სინქრონიზაცია, ფერების პრევიუ, Meta ტრანსკრიპტი, ხმის მომზადება და დამტკიცებული გეგმის Premiere XML ან რენდერი.
2. ახალი RAW მასალის კამერების/ხმების განაწილება, სინქრონიზაციის შემოწმება, ფერის არჩევანი და ეპიზოდის სამონტაჟო გეგმა ჯერ არსებულ აგენტურ/CLI ფლოუში მზადდება. სრული multicam timeline რედაქტორი ამ პანელში ჯერ არ არის.
3. უკვე აწყობილი ვიდეოდან რილსებისთვის მიუთითე ვიდეო და მისი სრული, შესაბამისი ტრანსკრიპტი. დაადასტურე რაოდენობა და დრო.
4. რედაქტორში ნახავ სრულ ტექსტს ტაიმკოდებით. შეასწორებ სიტყვებსა და დროებს, აირჩევ ჰუკს, ტიტრებს, ორიგინალ შრიფტს, ფერს, კონტურს, ზომასა და განლაგებას.
5. ჯერ შეინახე და გადაამოწმე, შემდეგ დაადასტურე. რენდერი ცალკე ღილაკით იწყება. შეუნახავი ცვლილებებისას დამტკიცება/რენდერი იბლოკება; ტექსტის შეცვლა ძველ დასტურს აუქმებს.

ჰუკი ნაგულისხმევად დასაწყისში ტიზერად გადადის და საუბარშიც რჩება. ტიტრები თითო კლიპზე ცალკე ირთვება. ფონტი ნამდვილი TTF/OTF ფაილიდან გამოიყენება. ტრანსკრიპციისთვის Meta რჩება ძირითად ძრავად; მისი მოდელი წინასწარ უნდა იყოს დაყენებული.

ახალი დავალებები რიგში ჩანს. წინა ექსპორტები ინახება. დასრულებული ვიდეო თავადაც გადაამოწმე. YouTube-ზე ავტომატური ატვირთვა ამ პანელს არ აქვს.

YouTube-ის კონტექსტის პირდაპირ მისაბმელად Settings-ში ადგილობრივი კავშირი მიაბი. YouTube პანელში გახსენი AI კავშირი, დააჭირე „Studio პროექტების ჩატვირთვა“, აირჩიე პროექტი და „კონტექსტის პროექტზე მიბმა“. გაიხსნება შესაბამისი პროექტის მეხსიერება. ამ ნაბიჯზე პროვაიდერს არაფერი ეგზავნება და AI არ იძახება. გადადის ტექსტი და ანალიტიკა, სურათის პიქსელები არ გადადის.
