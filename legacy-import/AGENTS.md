# YouTube archive and local clips

For episode/Shorts production read `skills/youtube-techcrush/SKILL.md` and its `references/podcut-flow.md`. Use Podcut Flow for new Meta transcription and the approved local review/render route. Ask count/duration first; show the whole timed transcript for correction/confirmation; ask captions on/off and original-font styling; prepend the approved spoken teaser and retain its later occurrence. Publishing needs an explicit user request.

For repository development, preserve recordings and private data outside Git. Run `node --test tests/selection.test.mjs` for selection changes. Do not start episode intake or ask production approval questions for coding/setup work. The Node archive scripts and Podcut's Python renderer are separate implementations; document their actual supported inputs.
