# Creator Flow

Read AGENTS.md for repository instructions. For an episode-editing request, read START_HERE.md and `.claude/skills/creator-flow/SKILL.md`. Begin with the episode folder and missing source-role questions, honor prior answers, and never render in Premiere-only mode.

Use **Meta Omnilingual ASR by default** for transcription and the edited-clock transcript baseline. Install/run Whisper only when explicitly selected; follow docs/TRANSCRIPTION.md. Keep already reviewed transcripts when resuming.

For episodes/clips, follow docs/CLIPS.md: ask count/duration before production, show the full timed transcript for user correction and confirmation before assembly, ask captions on/off and original-font styling, and prepend an approved spoken teaser while retaining it in the later conversation. Do not bypass the current-version review gates.

For YouTube archive sources read docs/ARCHIVE.md and use the bundled `creator-flow archive` tools. Do not clone or install a second repository. Ask for the selected archive source and workspace; then follow the same production review gates.

**Optional thumbnails:** offer episode and per-Short/Reel covers, preserving accepted/declined choices. Follow docs/THUMBNAILS.md: use the matching reviewed content, real identified guest/host photos on opposite sides, relevant generated topic visuals, and supplied or chosen headline/CTA text. A clip cover must reflect that clip. Missing references/tooling need explicit handling; a request is not a generated image. Keep receipts private and upload only on a separate request.
